# Fonts for the printable PDF

Latin subsets of the same typefaces the site uses, embedded when a
visitor downloads the checklist.

- `MarcellusSC-Regular.ttf`: Marcellus SC (Copyright 2012, Brian J.
  Bonislawsky DBA Astigmatic (AOETI)), reserved font name Marcellus.
  License: `MarcellusSC-OFL.txt`.
- `Inter-Regular.ttf`: Inter (Copyright 2016 The Inter Project Authors).
  License: `Inter-OFL.txt`.

Both are SIL Open Font License 1.1. Rebuild the subsets with
`pyftsubset` from the upstream TTF if the glyph set needs to grow.
